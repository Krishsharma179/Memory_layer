# MemoryOS

## What is MemoryOS?

MemoryOS is a memory operating system for personalized AI agents. It helps an AI maintain coherent, personalized, and context-aware conversations by organizing information in a hierarchical memory system.

The system manages short-term, mid-term, and long-term memory. It stores recent conversations, consolidates important information over time, retrieves relevant memories when needed, and uses them to generate more informed responses.

MemoryOS is designed as a modular architecture with four main responsibilities: storage, updating, retrieval, and generation. This allows it to work with different language models, embedding models, and storage backends.
